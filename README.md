# B3IT reproduction and extensions

This repository contains a scaled reproduction of B3IT and project extensions.

- `reproducibility/Figure1/` contains the three-model Figure 1 reproduction.
- `reproducibility/Figure2-3-Scaled-Comparison/` contains the Figure 2 baseline comparison and Figure 3 LoRA fine-tuning result contributed by Yousef.
- `extension/Hira-Safety-Prompt/` and `extension/Farah-Border-Input-Selection/` contain the existing project extensions.
- `extension/Youssef-Safety-Behavior/` contains Yousef's system-prompt and safety-LoRA experiments, notebooks, scripts, reviewed aggregate outcomes, and plots.

Each experiment folder documents its setup, interpretation, and limits. Model weights and raw question-response records are not included.
