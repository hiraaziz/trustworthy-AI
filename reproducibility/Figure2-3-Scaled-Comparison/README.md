# Scaled reproduction: Figures 2 and 3

This folder adds the two reproduction figures contributed by Yousef to the project repository.

## Figure 2: baseline comparison

`images/figure2_baseline_comparison.png` plots average ROC-AUC against estimated annual monitoring cost for B3IT, MET at temperatures 0 and 1, MMLU-ALG at temperatures 0 and 0.1, and LT on Qwen2.5-0.5B-Instruct. The dashed line is chance performance (ROC-AUC 0.5). The methods do not receive equal information: LT uses top-k log probabilities, while B3IT uses sampled output tokens.

## Figure 3: LoRA fine-tuning changes

`images/figure3_lora_finetuning.png` shows the detection curves over LoRA update counts from 1 through 512. The report describes a resource-limited LoRA substitute for the paper's full-weight fine-tuning experiment, using Qwen2.5-0.5B-Instruct, batch size 1, one epoch, learning rate $10^{-6}$, and rank-8 adapters. This result should be interpreted as a scaled LoRA experiment; it is not a reproduction of full-weight fine-tuning.

The images preserve the plots used in the report. They are result artifacts, not rerun outputs generated by the notebook currently in the local workspace; that notebook's model/settings do not match these figures. No claim of one-command regeneration is made here.
